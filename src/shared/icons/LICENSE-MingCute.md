# Ícones MingCute

Os desenhos dos ícones desta pasta vêm do **MingCute Icon** (https://www.mingcute.com, https://github.com/Richard9394/MingCute),
distribuídos sob a **Apache License 2.0** (https://www.apache.org/licenses/LICENSE-2.0). Foram convertidos em componentes
React (sem alterar os desenhos, só retirando a moldura transparente de 24x24) pelo script `scripts/icons/gen.py` do nexo-frontend.
